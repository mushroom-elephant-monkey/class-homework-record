# 班级作业收交情况记录

一个**单文件网页**，帮班主任记录和统计每天的作业收交情况。
支持多个班（打开先选班），双击就能用 —— 不需要安装、不需要注册、不需要联网。

默认给了 高一 / 高二 / 高三 各 3 个班，加 1 个测试班。**班号可以自己改**，见下面「自定义班级」。

---

## 先说清楚：适合谁，不适合谁

**适合**：想自己掌握学生数据、不愿意把名单交给第三方平台的老师；能双击打开一个文件的人。

**不适合**：完全不想碰文件的人。这个工具没有云端账号，数据存在你自己的浏览器里，
换电脑要手动导入导出一次。如果嫌麻烦，微信里那些现成的班级管理小程序会更省事。

> 说明白一点：这不是一个开箱即用的商业产品，是我做班主任时给自己用的一个工具。
> 有同行问起，就整理出来开源。它解决的问题很窄，只做一件事。

## 快速开始

**1.** 下载本仓库的 `index.html`

**2.** 双击，用浏览器打开（Chrome / Edge / 新版 Firefox 均可）

**3.** 打开后先**选一个班**（高一01、高二02……随便点一个试）

> 页头有个「下次直接进本班」的勾选框，默认是勾上的。测的时候建议先取消，
> 否则下次打开会直接跳到这个班。

**4.** 进入「设置 → 学生名单（分组）」

> 新班第一次打开时，里面已经放好了 **12 个虚构的示例学生**（分 3 组，每组 4 人），
> 每个班的名字都不一样，纯粹是为了让你一进去就看到界面长什么样。
> **这些名字都是编的，不对应任何真实学生。**
> 换成自己班：在这个框里**直接粘贴**你的名单覆盖掉即可，一行一个 `组号 姓名`：

```
1 张三
1 李四
2 王五
2 赵六
```

> ⚠ **组号和姓名之间必须有空格。**
> 写成 `1张三` 会解析失败 —— 整个班会被塞进第 1 组，而且姓名里还带着数字。这个坑我踩过。

**5.** 到「设置」里改掉默认密码

**6.** 回首页开始记录

> 📌 想先看看长什么样，就直接点 **「测试班」**——随便点、随便试，不影响其他班。
> 测试班旁边还有个「**便捷名单转换**」，把从别处复制来的名单整理成 `组号 姓名` 格式再粘贴。

## 每天怎么用

早读时打开，选科目、选作业项，按小组逐人点：

| 点击次数 | 状态 |
|---|---|
| 点一下 | 已交 |
| 再点一下 | 请假 |
| 第三次 | 回到未交 |

一次记录全班四五十人，约 **40–60 秒**。

**「请假不计入应交」是三态设计的核心。** 病事假和欠交是两回事，
混在一起，数据就不可信了 —— 老师不信，工具就白做。

---

## ⚠ 数据存在哪里（这一节最重要）

**数据保存在你当前浏览器的本地存储里，不上传任何服务器。**

| 情况 | 后果 |
|---|---|
| 换电脑、换浏览器 | 数据不会自动跟过去 |
| 清理浏览器数据 | **数据会丢** |
| 同一个文件用另一个浏览器打开 | 看到的是空白 |

**所以必须定期备份：**

- **备份**：设置 → `导出数据(JSON)` → 得到一个 `.json` 文件 → 存进网盘或 U 盘
- **恢复**：设置 → `导入数据(JSON)` → 选中那个文件 → 数据全部回来

一个班整个学期的数据也就几十 KB。**建议每周导一次。**

## 功能

- 三态记录：已交 / 请假 / 未交
- 按小组逐人点选，支持多科目、多种作业项
- 当日统计、本周汇总、自定义日期范围
- 按科目、按学生两个维度查看
- **未交名单**：一竖列对一次作业，直接照着催，不用再一张张翻
- **一键导出四张 Excel**：已交 √ / 未交 × / 全部 √×假 / 未交名单
- 免密时段：可设定每天某个时间段免密码操作，其余时间需要密码

## 自定义班级

班号写在 `index.html` 里的一段配置中。用记事本打开，搜 `CLASS_GROUPS` 就能看到：

```js
function seqClass(prefix, n){ const a=[]; for(let i=1;i<=n;i++) a.push(prefix + String(i).padStart(2,'0')); return a; }

const CLASS_GROUPS = [
  { name:'高一', classes: seqClass('高一', 3) },   // 高一01 – 高一03
  { name:'高二', classes: seqClass('高二', 3) },   // 高二01 – 高二03
  { name:'高三', classes: seqClass('高三', 3) },   // 高三01 – 高三03
  { name:'测试班（随便试，不影响真实班级）', classes: ['测试'], minor:true,
    tools:[ { id:'roster', label:'便捷名单转换' } ] }
];
```

| 想做什么 | 怎么改 |
|---|---|
| 每个年级 6 个班 | 把 `seqClass('高一', 3)` 里的 `3` 改成 `6` |
| 只用一两个年级 | 不需要的那几行整行删掉 |
| 用真实班号 | 不用 `seqClass`，直接写 `classes: ['2024级1班','2024级2班']` |
| 改名 | 改 `name:` 后面那串 |

⚠ **三条要记住：**

1. **班号就是按钮上显示的文字。** 写「高一01」就显示「高一01」，进班后页头自动加「班」字变成「高一01班」。
2. **班号同时是数据存储的键名**（`hw_checkin_data_v4_<班号>`）。**改班号等于换一份新数据**，原来的数据还在浏览器里，但页面找不到了。
3. 班号一旦开始录数据，**就别再改**。

> 🔴 **不要为了「一个班一个文件」复制多份 `index.html`。**
> 在 `file://` 下，同一浏览器的所有本地 HTML 共用同一份存储 —— 多份文件会互相覆盖，数据必丢。
> 多班就老老实实用选班页，一份文件足够。

## 技术说明

- **单文件**：HTML / CSS / JavaScript 全部在一个 `index.html` 里，约 2070 行、100 KB
- **零依赖**：不用框架、不用 npm、不用构建，改完刷新即可
- **零后端**：没有服务器、没有 API，不发起任何网络请求
- **可离线**：断网照常使用
- Excel 导出是手写的最小 OOXML + ZIP（store 模式），没有引入任何第三方库

> 想验证"真的不联网"，打开 `index.html` 搜 `fetch` 和 `XMLHttpRequest` —— 一个都没有。

## 隐私

- 不采集任何信息，没有埋点、没有统计上报
- 不向任何服务器发送数据（代码里没有任何 `fetch` / `XMLHttpRequest`）
- 学生名单只存在于你自己的浏览器中

想验证的话，直接搜 `index.html` 里的 `fetch` —— 一个都没有。

## 已知问题

- **改学生姓名 = 删旧 + 加新，该生的历史记录会丢。** 尽量别改名，先把名单录对。
- 只调整小组归属不影响记录（记录与内部编号绑定，与组号无关）。
- 名单录错想大改，建议先导出一份备份。

## 一点背景

这个工具最初是为了解决一个很具体的小事：每天早上清点谁没交作业。

纸质名单点一遍、微信群里问一圈、再抄一张未交名单给课代表 —— 每天十几分钟，
学期末还查不出某个学生到底交过几次。真正麻烦的不是"记录"，是**记完之后要数、要汇总、
要回溯**。

所以它只做了三件事：点得快（三态、按组点选）、查得到（按人按科目回溯）、
算得清（四张表直接导出打印）。

如果你也在为同样的事花时间，拿去用就是了。
